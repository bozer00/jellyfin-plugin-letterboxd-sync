# Security policy

## Supported versions

Security fixes are made on the current `main` branch and the latest published plugin versions. Older catalog entries are not maintained.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/bozer00/jellyfin-plugin-letterboxd-sync/security/advisories/new) and include:

- the affected plugin and version;
- the Jellyfin version and deployment type;
- clear reproduction steps and impact; and
- a safe way to contact you.

Please do not include credentials, private Letterboxd data, user IDs, server URLs, or unredacted logs. Acknowledgement is targeted within 7 days; public disclosure is coordinated after a fix or mitigation is available.
